# YT-zen v3.12.6

## Firefox runtime fixes

- Fixes the recurring `ReferenceError: can't access lexical declaration 'u' before initialization` from Session History: the ended-listener binder was invoked before its `const` declaration, aborting module setup and re-throwing on every navigation event.
- Stops `Cross-Origin Request Blocked` console errors for `data:` tracking URLs: the legacy playback-tracking replay now only beacons `http(s)` URLs.
- Removes the inline `<script>` injection in the fast-forward path that YouTube's CSP blocked, eliminating the blocked-script console error; the same seek/rate operations are applied through the player API directly.
