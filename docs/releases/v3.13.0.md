# YT-zen v3.13.0

## Feature trim (shipped artifact is canonical)

The 3.13.0 artifact prunes several feature registrations to keep the shipped script lean. The
source mirrors in `src/` are re-synced to the artifact so `npm run build` reproduces it byte for byte:

- Smart Speed, Search Remix, Watch Genome, Time Budget Manager, DeArrow Titles & Thumbnails,
  and Dislike Meter feature registrations were removed.
- The Monolith Overlay Hub settings no longer duplicate per-monitor toggles; monitors join and
  leave the hub automatically as they are toggled elsewhere.
- Feature summaries shortened across the settings dashboard.

## Build pipeline hardening

- `package.json` is now the single source of truth for the version: `scripts/build-userscript.js`
  stamps `@version` into both `yt-zen.user.js` and `yt-zen.meta.js`, so package/artifact/metadata
  can no longer drift apart (the drift previously failed `scripts/check-release.js`).
- `scripts/check.js` now performs true parse-only validation under Bun (`Bun.Transpiler`) as well;
  under Node the existing `node --check` gate is unchanged.
- `yt-zen.meta.js` header re-synced with the artifact header: adds the `lz-string@1.5.0` and
  `culori@3.2.0` `@require` entries; drops dead `@connect` entries (`huggingface.co`,
  `doubleclick.net`, `returnyoutubedislikeapi.com`) whose features are no longer present.
