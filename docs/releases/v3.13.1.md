# YT-zen v3.13.1

## Stable re-release of the 3.13.0 artifact

The `v3.13.0` git tag was cut from a pre-fix commit while CI was red, and its GitHub asset was
built from the pre-fix tree and shipped without `yt-zen.meta.js`. No code regressed since — this
patch release republishes the corrected stable artifact through the now-hardened pipeline so the
downloaded file matches the repository byte for byte:

- Includes the build-pipeline fixes from `3d46889`: `package.json` is the single version source,
  `@version` is stamped into both `yt-zen.user.js` and `yt-zen.meta.js`, and the meta header is
  re-synced with the artifact (`lz-string@1.5.0` / `culori@3.2.0` requires, dead `@connect`
  entries dropped).
- Both release assets (`yt-zen.user.js`, `yt-zen.meta.js`) are attached again, restoring the
  house release shape.

## Test harness hardening

- `scripts/test-unit.js` keeps one event-loop handle alive across pure-microtask stretches:
  under Bun 1.3.x on Windows the loop could drain and exit 0 mid-test with no output, making
  the suite a silent false-green. Assertions now always run to completion; failures print and
  set a non-zero exit code.
