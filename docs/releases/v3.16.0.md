# YT-zen v3.16.0

The largest release yet: a third full-codebase audit (22 parallel line-range reviews, semantic
lens) plus **thirty new advanced features**.

## Audit: regressions fixed in our own v3.15.x code

- **Discover was completely broken** — a refactor closed over the wrong scope, so every topic
  load threw `ReferenceError` and the panel only ever showed "Search failed". Fixed.
- **Perf-mode granular toggles snapped back to their preset** on every apply/reload; syncing now
  runs once per level change via a persisted marker.
- **Perf-mode tier lookups used display-case keys against camelCase tables** — tier
  contributions silently resolved to `undefined` (Maximum's extra paint-reduction never fired).
- **Shorts Policy "allow" mode gated Shorts 24/7** when the time window was unset or malformed,
  contradicting its own documented contract; both modes now deactivate on invalid times.
- **Overlay Hub's idle backoff never woke up** on toggle/nav, and already-hubbed monitors kept
  the poll pinned at full speed forever.
- **Session Replay pruning kept the oldest 500 records and deleted the newest** — cursor
  direction was inverted.

## Audit: pre-existing defects

- **Every Discover/Remix search filter was ignored**: requests sent filters under `sp:` while
  InnerTube expects raw base64 under `params:`. All duration/date/quality filters work now.
- **Resume play-gate never engaged**: `Je()` set the awaiting-resume flag and then immediately
  cleared it via its own cleanup; autoplay resumed behind the overlay. Ordering fixed.
- **SponsorBlock**: HUD Undo could not work (cooldown + processed-mark re-executed the skip);
  skip targets are clamped to video duration so stale segment data can't jump to EOF;
  overlapping segments from different categories no longer defeat the binary search;
  synthetic local ids are never posted to vote/viewed endpoints; api-error metrics stopped
  double-counting; clipboard user-ID copy reports failure honestly.
- **Force-Watched on DVR/live streams** returned after mutating player methods and settings,
  bricking next-video for the page lifetime — the live guard now runs before any mutation, and
  the forced-end path handles rejected `play()` promises.
- **uBlock filter engine**: stateful `g/y` regex flags made path/text matching alternate;
  `:has-text()` patterns containing parentheses corrupted their selectors during stripping;
  unparseable `:matches-path()` tokens turned scoped filters into hide-everywhere; `~domain`
  negation is now honored; whole-page procedural filters (`*`) no longer serialize every DOM
  node every pass.
- **Geo Override**: PREF cookies round-tripped through decode-before-split, corrupting values;
  cookie/ytcfg writers now respect the feature gate and stop re-applying after disable; beacon
  disable no longer over-restores the navigator/Intl patches; restores delete patched own
  properties instead of installing snapshot getters.
- **Share shortener preserved only `?t=`**, destroying playlist context (`list`/`index`) on
  cleaned links — meaningful params survive.
- Shared `Dom.when()` leaked its poll interval on every successful resolve; `Dom.css()`
  re-invocation updated stale stylesheets instead of silently keeping them; `ResourceScope.fetch`
  forwards caller abort signals into teardown; thumbnail fetch timeout covers body reads; blob
  URLs enter tracking and revoke displaced entries; version comparison parses numerically
  ("0.11" vs "0.9"); config sanitizer stops coercing empty strings into zero defaults; toast
  click actions can no longer leak onto unrelated future toasts; update checks compare versions
  correctly; theme palettes gained a distinct "Graphite Light"; settings import runs legacy-key
  migrations; net-monitor counts bytes (not UTF-16 code units); search-result badges refresh
  numbering; dashboard open/close races resolved.

## New: 30 features

**Playback intelligence**
1. **Silence Fast-Forward** — audio-analyser detection speeds through quiet stretches (2–8×).
2. **Chapter Auto-Skip** — keyword-driven skipping of intro/outro/sponsor chapters.
3. **Pause Rewind** — hop back N seconds on every pause.
4. **Instant Replay** — Alt+J replays the last N seconds.
5. **Frame Stepper** — player buttons + Alt+, / Alt+. nudge exactly one frame at any FPS.
6. **Playlist Resume** — long playlists offer one-click resumption at exact index/time.
7. **Per-Channel Volume** — remembers preferred loudness per channel.
8. **Sleep Timer** — Alt+O cycles 30/60/90 min; volume fades before pausing.

**Study & organization**
9. **Timestamp Bookmarks** — Alt+B drops named marks; jumpable list under the description.
10. **Study Notes** — Alt+N quick-capture pad with Markdown export.
11. **Quick Save to Collection** — one-click send of the current video into any collection.
12. **Queue Shuffle** — Fisher-Yates over the local queue via Alt+U.
13. **Playlist Watch-Marks** — dims playlist entries you've already watched.
14. **Duplicate Title Spotter** — flags near-duplicate uploads on search pages.

**Wellbeing**
15. **Session Intention** — one prompt: what are you here for? Your answer floats quietly.
16. **End-of-Video Wind-Down** — autoplay waits behind a calm interstitial until you continue.
17. **Shorts Marathon Guard** — gentle nudges after N consecutive Shorts.
18. **Stretch Reminder** — periodic nudge during uninterrupted watching.
19. **Zen Breather** — Alt+G opens a 60-second guided breathing circle.

**Privacy & feeds**
20. **Copy Link Cleaner** — strips si/feature/utm params from copied YouTube URLs.
21. **Feed Freshness Filter** — hides home-feed uploads older than your chosen age.
22. **Channel Snooze** — mute listed channels across feeds without unsubscribing.
23. **Comment Filter** — hides comments matching your keywords.
24. **History Local Hide** — Shift+click masks history rows locally; nothing deleted upstream.

**Interface & accessibility**
25. **Night Theme Scheduler** — dark/light by clock window (TimeWindow-based).
26. **Reading Size Boost** — larger description/comment text without page zoom.
27. **Ambient Glow** — canvas-sampled bias lighting around the player.
28. **Description Reader** — calm reader overlay for long descriptions.

**Diagnostics**
29. **Storage Dashboard** — per-store IndexedDB footprint + browser quota + trim action.
30. **Health Check** — self-diagnostics: subsystem stats, quarantines, live selector probes.

All thirty ship disabled by default, follow the registry contract (ctx-managed timers,
teardown stacks), and expose dashboard toggles.
