# YT-zen v3.16.1

A third full-codebase audit at maximum parallelism — 32 concurrent line-window reviewers plus
four cross-cutting specialists (hotkey collision matrix, overlay/z-index stack map,
config triple-bookkeeping, storage namespace registry) — applying current elite-review
rubrics (memory-leak quadrants, stale-async cancellation, AI-authorship skepticism).

## Critical regressions fixed (introduced in earlier releases this cycle)

- **Dashboard could never reopen after its first close** — a corrupted identifier
  (`wo = nullull`) threw on every close, leaving stale open-state forever.
- **Hide-elements panel was silently truncated** — six empty catalog stubs crashed row
  rendering mid-build, killing ~200 rows, the filter box, and the un-hide-all button.
- **Timestamp-suppression regex lost its capture group** during a prior fix — `#t=`/`?t=`
  links no longer suppressed the resume prompt.
- **A/B Repeat force-resumed paused videos** (comma-operator precedence) and went permanently
  dead after an off/on toggle (stale expando guard → WeakSet).
- **Theme-card highlight sync died after first dashboard close** (once-latch vs bus-drain);
  now re-registers per render.
- **Two settings reset themselves every launch**: `algoAutoDislikeOn` and SponsorBlock's
  `sbUserId` were missing from the defaults ledger, so the load-time sanitizer stripped them.
- **Queue Shuffle removed** honestly: it had no data source (the local queue has no producers),
  so Alt+U could never do anything.

## Engine correctness

- FinalizationRegistry cells now use real tokens and non-reaching held values (previously the
  registry pinned every observed target forever, making GC recovery impossible).
- Pagehide maintenance checkpoint can actually bypass the kv-cleanup throttle (force flag).
- `ResourceScope.fetch` binds the wire to the scope controller; caller signals forward into it.
- `Dom.when` timeout path clears its poll interval (success path was fixed earlier; timeout
  still leaked one interval per timed-out wait).
- SharedTicker honors mid-tick removals; resume play-gate installs exactly once (no nested
  wrappers); player lookup happens before resume flags commit; the 30-second stale-card timer
  is tracked and cleared on navigation.
- Innertube visitor header is string-coerced like its siblings; SponsorBlock responses get a
  size cap before parse and normalized-output clamp exposure reduced.

## Features corrected (post-release pack review)

- **Silence Fast-Forward** fails closed: unknown audio (no analyser / suspended context /
  muted playback) no longer counts as silence, and the captureStream tap is released on
  teardown.
- **Chapter Auto-Skip** waits for the page's player response to actually match the new video
  before pinning chapters (SPA nav previously skipped chapters of the wrong film).
- **Sleep Timer** restores faded volume when re-armed mid-fade and captures original volume
  lazily at first fade tick.
- **Stretch Reminder** resets its streak on play-after-long-pause (old math made the threshold
  unreachable).
- **End-of-Video Wind-Down** holds only the main player (hover previews unaffected), survives
  YouTube's autoplay navigation instead of defeating itself, and sits above other full-screen
  gates.
- **Feed Freshness** truly gates to the home feed; **Channel Snooze** respects co-ownership of
  card visibility with Freshness; **History Local Hide** no longer hijacks Shift+click outside
  history.
- **Night Theme Scheduler** stands down when you flip themes manually and restores your
  previous state on disable (previously left forced-dark stuck).
- **Playlist Watch-Marks** memoizes history lookups per navigation (was O(rows²) IDB reads on
  long playlists); playlist-resume and channel-volume maps are now size-capped.
- All Alt-hotkeys ignore key auto-repeat (holding Alt+B no longer spawns dozens of bookmarks).
- Element binder retries until the player mounts, so features applied on the home page work
  after navigating to a video.
- Study-notes export registers once (no duplicate downloads); Shorts views no longer file
  notes under an empty key.

## Cross-cutting

  branches now exclude ctrl/alt/meta like their siblings.
- Perf-mode's kill-blur rule no longer strips glass/shadows from YT-zen's own overlays.
- Settings import runs legacy-key migrations (parity with boot path) and surfaces file-read
  errors; export watchdog probe recognizes both style-id families.
- Geo Override: beacon-only disable no longer tears down navigator/Intl spoofs; sub-toggle off
  restores its own patch; cookie deletion covers both domain scopes; PREF round-trips encoded;
  panel actions respect the master gate. Net-monitor disables restore fetch/XHR/beacon natives.
- Net-monitor hour rollover swaps-and-clears before awaiting IDB (no more discarded triggering
  request); remaining UTF-16 length accounting converted to byte sizes; adaptive-throttle seeds
  hidden-state when applied mid-hide.
- Channel blocker: path-block loop honors domain scoping; stale Block-button flags clear on
  disable; channel-name normalization is NFC-consistent; dead closure removed.
- Dashboard: caption font picker writes to the correct settings key (was persisting font names
  as keys), Esc closes as advertised, pointer listeners stop leaking per open.
- Storage ledger: playlist-resume/channel-volume maps capped; theme palettes re-verified
  schema-complete across all 200 entries.
