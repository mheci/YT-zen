# YT-zen v3.9.0

## Summary

This release completes the production architecture pass after v3.8.0.

## SponsorBlock

- Reconstructed direct and privacy-prefix lookup handling from the documented SponsorBlock API contract.
- Requests every supported category and action type by default.
- Revalidates cached videos on every load and recovers after tab wake-up, autoplay, playlist changes, history navigation, and player replacement.
- Prevents stale generations and aborted requests from mutating the active video.
- Validates, sorts, bounds, and de-duplicates server segments.
- Corrects manual vote, viewed-report, user-info, and submission request parameters.
- Simplifies category action controls and removes the diagnostics button from user settings.

## Resources and compatibility

- Adds concurrent factory deduplication to `BoundedCache`.
- Strengthens resource teardown and shared lifecycle ownership.
- Removes dependency on `AbortSignal.timeout` from optional feature mirrors.
- Escapes imported session, collection, cookie, and discovery values before rendering.
- Adds deterministic CI checks and a release workflow.
