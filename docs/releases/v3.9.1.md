# YT-zen v3.9.1

## Firefox runtime fixes

- Declares the Session Restore cleanup timer before teardown runs, removing the `assignment to undeclared variable mt` runtime exception.
- Makes Cookie Control, geo override, high-frame-rate, and theme cookie writes host-only instead of emitting invalid cross-context domain attributes.
- Restricts cookie names accepted by Cookie Control edits to valid cookie-token characters.
